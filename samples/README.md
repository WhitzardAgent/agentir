# AgentIR Sample Trajectories

These samples demonstrate AgentIR's core capability: **one source trajectory -> many target formats**.

## The Same Conversation, Five Expressions

| Format | File Pattern | Use Case | Characteristics |
|---|---|---|---|
| OpenAI Chat | `*.openai.json` | OpenAI API / SFT | Simple `role`+`content` structure, `tool_calls` array |
| Anthropic Tools | `*.anthropic.json` | Anthropic API / Tool-Use | Typed content blocks (`text`, `tool_use`, `tool_result`) |
| OpenHands | `*.openhands.json` | SWE-Bench / Coding Agent | `trajectory` array with `model_patch` |
| Hermes XML | `*.hermes.xml` | Nous / Reasoning | `from`/`value` pairs with XML `<thinking>` tags |
| AgentIR Canonical | `*.agentir.json` | Universal / Re-conversion | Full event graph with provenance, actions, observations |

### terminus-2 Format

AgentTrove uses the **terminus-2 harness format** — a ShareGPT-style conversation layout where:

- Each row is a complete agent trajectory as `conversations` (list of `{role, content}`)
- Roles: `user` (environment/terminal output), `assistant` (agent response), `tool`
- Assistant responses contain JSON with `analysis` (reasoning) and command fields
- User turns contain terminal output, warnings, and environment state
- Generated by the [Harbor](https://github.com/harbor-framework/harbor) agentic framework

## Conversion Command (one command per format)

```bash
# AgentIR Canonical (via DSL convert)
agentir dsl convert dsl/formats/agenttrove.agentir.yaml data.jsonl -o output.agentir.jsonl

# Target formats (via agentir-llc)
agentir-llc --input output.agentir.jsonl --target openai-tools --output output.openai.jsonl
agentir-llc --input output.agentir.jsonl --target anthropic-tools --output output.anthropic.jsonl
agentir-llc --input output.agentir.jsonl --target openhands --output output.openhands.jsonl
agentir-llc --input output.agentir.jsonl --target hermes-xml --output output.hermes.jsonl --include-reasoning
```
